## Registrar el comercio

Hacé un `POST /api/v1/integrations/register` con el nombre, correo de contacto y CUIT de 11 dígitos del comercio. Esta operación de alta es pública. Reemplazá los datos de ejemplo por los de tu comercio.

```bash
curl "$WALLET_API_URL/api/v1/integrations/register" \
  -H "Content-Type: application/json" \
  --data '{"companyName":"Comercio de ejemplo","contactEmail":"comercio@example.com","cuit":"30712345678"}'
```

La respuesta `201` contiene `apiKey` y los identificadores del comercio y su billetera. Guardá la clave al recibirla. Padi entrega su valor una sola vez durante el alta.

## Usar la API Key

Conservá la clave como secreto en tu servidor, por ejemplo en `WALLET_MERCHANT_API_KEY`. Enviá `X-Api-Key: <apiKey>` para crear links y consultar tus cobros. Si la API devuelve `401`, verificá la clave y el encabezado.

Las URLs del checkout y del QR se pueden compartir con el comprador. Los endpoints públicos de consulta y QR funcionan sin API Key.
