Con tu [cuenta de vendedor](/crear-cuenta-vendedor), entrá a **Cobros** desde el menú de Padi. En la pantalla **Cobros y Ventas** podés ingresar el importe y el concepto y generar el enlace con su código QR.

## Crear el cobro

<Steps>
  <Step title="Abrí Nuevo cobro">
    Iniciá sesión en [la aplicación Padi](https://padi-billetera.netlify.app/) y elegí **Cobros**. Al terminar el registro también podés llegar con **Ir a cobrar**.

    ![Pantalla Cobros y Ventas con el formulario Nuevo cobro y el listado vacío](/images/nuevo-cobro-vendedor.png)
  </Step>
  <Step title="Completá el pedido">
    Ingresá **Importe a cobrar**, **Concepto o producto** y, si lo necesitás, **Detalle adicional (opcional)**.

    Por ejemplo, un importe de **1.500 pesos**, el concepto **Pedido 1042** y el detalle **Remera talle L**. El importe debe ser mayor que cero y el concepto es obligatorio.
  </Step>
  <Step title="Generá el enlace">
    Pulsá **Generar link y QR**. Cuando termina la solicitud, aparece **Esperando pago del cliente**, junto con el importe, el concepto, el detalle si lo completaste y el QR.

    El cobro también aparece en **Cobros generados recientemente**, con su fecha, importe y estado **Activo**.
  </Step>
  <Step title="Compartilo con el comprador">
    Pulsá **Copiar link** para copiar la dirección y enviársela al comprador, o mostrale el QR para que lo escanee.

    **Abrir checkout** permite revisar la pantalla de pago correspondiente al cobro.
  </Step>
</Steps>

## Opciones disponibles

| Campo o acción | Comportamiento |
| --- | --- |
| Importe a cobrar | Importe en pesos argentinos, mayor que cero. |
| Concepto o producto | Obligatorio, hasta 100 caracteres en el formulario. |
| Detalle adicional | Opcional, hasta 160 caracteres en el formulario. |
| Generar link y QR | Crea el cobro y muestra el enlace y el QR. |
| Copiar link | Copia el enlace de pago para que puedas enviárselo al comprador. |
| Abrir checkout | Abre la pantalla de pago del cobro. |
| Ver código QR | Permite volver a mostrar el QR desde un cobro reciente. |

La pantalla no ofrece seleccionar moneda, configurar vencimiento ni elegir entre uso único y múltiple. Esas opciones no forman parte de este formulario.

## Revisar el checkout

El checkout muestra el concepto, el detalle y el total. Si lo abrís con la misma cuenta que creó el cobro, aparece **Cobro propio** y el mensaje que indica que no podés pagarlo con tu propia cuenta. Compartí el link con el comprador.

El estado **Esperando pago del cliente** confirma que se generó el enlace, no que ya se recibió el pago. Este recorrido se verificó creando un enlace de prueba por **$1.500**, sin completar un pago ni comprobar una acreditación.
