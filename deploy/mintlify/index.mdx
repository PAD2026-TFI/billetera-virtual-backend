Padi permite que tu aplicación genere un enlace de pago y envíe al comprador al checkout. Tu servidor crea el cobro con la API Key del comercio y consulta el resultado para actualizar el pedido.

Esta documentación está dirigida a desarrolladores de aplicaciones externas que integran la pasarela.

## Direcciones del servicio

| Servicio | URL | Uso |
| --- | --- | --- |
| API | `https://padi.runasp.net` | Alta del comercio, creación de enlaces y consulta de cobros. |
| Aplicación Padi | [padi-billetera.netlify.app](https://padi-billetera.netlify.app/) | Interfaz de la billetera para sus usuarios. |
| Documentación | [padi-api.mintlify.site](https://padi-api.mintlify.site/) | Guías y referencia de integración. |

En los ejemplos, definí la URL base de la API sin agregar `/api/v1`:

```bash
export WALLET_API_URL="https://padi.runasp.net"
```

## Primera integración

1. [Registrá el comercio y obtené su API Key](/autenticacion).
2. [Creá un enlace de pago y abrí el checkout](/cobros).
3. [Consultá el cobro y conciliá el pedido](/confirmacion-de-pagos).

Conservá las credenciales y las llamadas autenticadas en tu servidor. El navegador del comprador recibe el enlace de checkout.

<Note>
Los ejemplos usan datos ficticios. La URL indicada es el backend alojado del proyecto; esta guía no presupone que exista un entorno sandbox separado.
</Note>
