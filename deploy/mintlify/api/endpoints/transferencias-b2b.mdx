Usá esta operación desde tu servidor para transferir saldo de prueba a otra billetera Padi. Podés usar la **misma API Key de Vendedor** que generaste en [Integraciones](/integraciones) para crear enlaces y consultar cobros. Padi identifica la billetera de origen a partir de la clave y debita el saldo de la billetera donde recibís tus cobros. Las claves activas de clientes externos también son válidas.

## Enviá la transferencia

Hacé un `POST` a `https://padi.runasp.net/api/v1/integrations/transfers` con `Content-Type: application/json` y tu clave en `X-Api-Key`.

Generá y guardá un UUID por retiro antes de enviarlo por primera vez. Mandalo en `Idempotency-Key` y reutilizalo si tenés que repetir la solicitud. El encabezado es opcional para la API. Si lo omitís, Padi genera una clave nueva para cada llamada y un reintento puede crear otra transferencia.

En el JSON, mandá el importe y **exactamente uno** de los tres campos de destino.

| Campo | Qué enviar |
| --- | --- |
| `amount` | Importe obligatorio en ARS, entre 0,01 y 780.400,00, con hasta dos decimales. |
| `alias` | Alias de Padi de 6 a 40 caracteres. Admite letras, números, puntos y guiones. |
| `cvu` | CVU de Padi como texto de 22 dígitos. Así conserva los ceros iniciales. |
| `destinationWalletId` | UUID de la billetera destino. |

<CodeGroup>

```json Alias
{
  "alias": "jugador.padi",
  "amount": 2000
}
```

```json CVU
{
  "cvu": "0000123400000000000123",
  "amount": 2000
}
```

```json ID de billetera
{
  "destinationWalletId": "c7a40b93-5491-4cf1-bf50-136faad91b94",
  "amount": 2000
}
```

</CodeGroup>

## Ejemplo desde el servidor

En este ejemplo, `retiro` representa una solicitud que ya guardaste. Su `idempotencyKey` es el UUID persistido para esa operación.

```javascript JavaScript para servidor
async function enviarRetiro(retiro) {
  const response = await fetch('https://padi.runasp.net/api/v1/integrations/transfers', {
    method: 'POST',
    headers: {
      'X-Api-Key': process.env.PADI_API_KEY,
      'Idempotency-Key': retiro.idempotencyKey,
      'Content-Type': 'application/json',
    },
    body: JSON.stringify({ alias: retiro.alias, amount: retiro.amount }),
  });

  const result = await response.json();
  if (!response.ok) {
    throw new Error(`Padi respondió HTTP ${response.status}: ${result.code ?? 'sin código'}`);
  }
  return result;
}
```

## Confirmá el retiro

Una transferencia nueva devuelve **201 Created** y el encabezado `Idempotency-Replayed: false`. Un reintento con la misma clave, billetera destino resuelta e importe devuelve **200 OK** con `Idempotency-Replayed: true` y la transferencia original. Si el alias cambió y apunta a otra billetera, la misma clave devuelve un conflicto.

La respuesta incluye `id`, `sourceWalletId`, `destinationWalletId`, `amount`, `currency`, `status` y `createdAt`. Cuando recibas el estado `Completed`, guardá el ID de la transferencia en tu solicitud y marcala como pagada una sola vez. Si se pierde la respuesta, mantenela pendiente y reintentá con la clave y los datos que guardaste. Si no podés reconciliar el resultado, revisá la operación antes de generar otro envío.

## Respuestas de error

| HTTP | Código o situación | Qué revisar |
| --- | --- | --- |
| 400 | `INVALID_INPUT` o validación del JSON | Mandá un solo destino válido, un importe y un UUID válido si enviás la clave. |
| 400 | `INVALID_AMOUNT` | Revisá el rango y la cantidad de decimales del importe. |
| 400 | `SAME_WALLET` | Elegí una billetera destino distinta a la emisora. |
| 401 | API Key ausente, inválida o revocada | Revisá el encabezado `X-Api-Key` y el estado de tu clave. |
| 403 | Permiso insuficiente para transferir | Usá una API Key activa de Vendedor o de cliente externo con acceso a la operación. |
| 404 | `SOURCE_WALLET_NOT_FOUND` | Verificá que la integración tenga una billetera. |
| 409 | `INSUFFICIENT_FUNDS` o `DESTINATION_BALANCE_LIMIT` | Revisá el saldo de origen o el límite de saldo del destinatario. |
| 409 | `IDEMPOTENCY_CONFLICT` | Revisá el importe y la billetera asociados a la clave original. |
| 409 | `CONCURRENCY_CONFLICT` | Reintentá con la misma clave. |
| 422 | `DESTINATION_UNAVAILABLE` | Revisá que el destino exista y esté activo. |

Guardá una sola API Key en el servidor de tu comercio para [crear enlaces de cobro](/api/endpoints/crear-cobro) y enviar los retiros desde la billetera asociada.
