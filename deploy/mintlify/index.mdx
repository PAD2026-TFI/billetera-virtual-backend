---
title: "Integrá la pasarela de Padi"
description: "Creá un link de pago, enviá al comprador al checkout y verificá el cobro."
---

Padi aloja el checkout. Tu servidor crea el link de pago y consulta el resultado. El comprador abre el link o escanea el QR para pagar en Padi.

1. Registrá tu comercio y guardá la API Key. [Alta y autenticación](/autenticacion)
2. Creá un link con el importe de tu pedido y redirigí al comprador a `checkoutUrl` o mostrá el QR. [Guía de cobros](/cobros)
3. Consultá el pago desde tu servidor antes de marcar tu pedido como pagado.

| Operación | Cuándo usarla |
| --- | --- |
| `POST /api/v1/integrations/register` | Dar de alta el comercio y obtener la API Key. |
| `POST /api/v1/integrations/payment-links` | Crear un cobro para un pedido. |
| `GET /api/v1/integrations/payment-links/{id}` | Consultar el estado de un link propio. |
| `GET /api/v1/integrations/received-payments` | Listar cobros recientes del comercio. |
| `GET /api/v1/integrations/received-payments/{paymentId}` | Verificar un cobro concreto. |
| `GET /api/v1/public/payment-links/{token}` | Mostrar los datos públicos de un link. |
| `GET /api/v1/public/payment-links/{token}/qr` | Obtener el QR para abrir el checkout. |

En los ejemplos, `WALLET_API_URL` es la URL HTTPS base de la API del entorno que estés usando, sin agregar `/api/v1`.
