Padi permite a comercios y plataformas externas suscribir una URL HTTPS para recibir notificaciones automáticas en tiempo real en cuanto un pago se confirma exitosamente (`payment.succeeded`).

Cada notificación viaja protegida con una firma criptográfica en el encabezado `X-Padi-Signature` generada con tu `WebhookSecret`, garantizando la autenticidad e integridad del payload.

## Parámetros de configuración

Enviá tu solicitud autenticada con tu `X-Api-Key`:

- `webhookUrl`: URL HTTPS pública de tu servidor que escuchará los eventos POST (hasta 2048 caracteres).
- `webhookSecret`: Clave secreta compartida de al menos 32 caracteres (hasta 256 caracteres) utilizada para firmar los payloads.

<CodeGroup>

```powershell PowerShell
$apiBase = 'https://padi.runasp.net'
$headers = @{
    'X-Api-Key' = $env:PADI_API_KEY
    'Content-Type' = 'application/json'
}
$body = @{
    webhookUrl = 'https://mitienda.com/api/padi/webhook'
    webhookSecret = 'mi_secreto_super_seguro_de_al_menos_32_caracteres_12345'
} | ConvertTo-Json

$configuracion = Invoke-RestMethod -Method Put `
    -Uri "$apiBase/api/v1/integrations/webhook" `
    -Headers $headers -Body $body

$configuracion | Select-Object companyName, webhookUrl
```

```javascript JavaScript para servidor
const apiBase = 'https://padi.runasp.net';
const apiKey = process.env.PADI_API_KEY;

const response = await fetch(`${apiBase}/api/v1/integrations/webhook`, {
  method: 'PUT',
  headers: {
    'X-Api-Key': apiKey,
    'Content-Type': 'application/json',
  },
  body: JSON.stringify({
    webhookUrl: 'https://mitienda.com/api/padi/webhook',
    webhookSecret: 'mi_secreto_super_seguro_de_al_menos_32_caracteres_12345',
  }),
});

const data = await response.json();
console.log('Webhook configurado:', data.webhookUrl);
```

</CodeGroup>

## Estructura de la notificación recibida

Cuando un comprador o usuario paga un enlace, Padi envía inmediatamente una petición HTTP `POST` a tu `webhookUrl` con el siguiente cuerpo JSON:

```json
{
  "event": "payment.succeeded",
  "data": {
    "paymentId": "4e3b0f74-c11d-402d-9030-aa2c02243051",
    "paymentLinkId": "11111111-1111-4111-8111-111111111111",
    "token": "0123456789abcdef0123456789abcdef",
    "amount": 1500.00,
    "currency": "ARS",
    "status": "Completed",
    "paymentMethod": "VirtualCard",
    "authorizationCode": "WALLET-DEBIT",
    "transferId": "e6e50f77-0edb-4983-80cd-61b61bad976b",
    "completedAt": "2026-11-10T23:10:00+00:00"
  },
  "occurredAt": "2026-11-10T23:10:00+00:00"
}
```

## Validación de la firma HMAC-SHA256

Para verificar que la notificación proviene legítimamente de Padi y no fue alterada por terceros:

1. Obtené el encabezado `X-Padi-Signature` de la petición entrante.
2. Leé el cuerpo crudo (raw bytes / raw string) de la solicitud HTTP sin formatear.
3. Calculá el HMAC-SHA256 del cuerpo utilizando tu `webhookSecret` configurado.
4. Convertí el hash resultante a hexadecimal en minúsculas y comparalo en tiempo constante con el valor recibido.

```javascript Ejemplo de validación en Node.js (Express)
import crypto from 'node:crypto';

app.post('/api/padi/webhook', express.raw({ type: 'application/json' }), (req, res) => {
  const signature = req.headers['x-padi-signature'];
  const secret = process.env.PADI_WEBHOOK_SECRET;

  const expectedSignature = crypto
    .createHmac('sha256', secret)
    .update(req.body)
    .digest('hex');

  if (!crypto.timingSafeEqual(Buffer.from(signature), Buffer.from(expectedSignature))) {
    return res.status(401).send('Firma inválida');
  }

  const payload = JSON.parse(req.body.toString('utf-8'));
  console.log(`Pago recibido: ${payload.data.paymentId} por $${payload.data.amount}`);

  // Responder 200 OK inmediatamente
  res.status(200).json({ received: true });
});
```

## Desactivar o desuscribir el webhook

Si necesitás pausar las notificaciones, podés llamar al endpoint de desactivación:

```bash cURL
curl -X DELETE "https://padi.runasp.net/api/v1/integrations/webhook" \
  -H "X-Api-Key: $PADI_API_KEY"
```
