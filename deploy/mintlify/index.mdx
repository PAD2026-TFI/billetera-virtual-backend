Padi permite generar enlaces de pago desde la aplicación de la billetera y desde una integración externa. En ambos recorridos, el comprador abre un checkout para ver el cobro.

Esta documentación está dirigida a quienes integran la pasarela y necesitan entender también cómo opera un vendedor en la aplicación publicada.

## Empezar desde la aplicación

1. [Creá una cuenta de vendedor](/crear-cuenta-vendedor) en Netlify.
2. [Generá y compartí un link de cobro](/cobrar-desde-app) desde **Cobros y Ventas**.

El registro de vendedor no entrega una API Key. Para automatizar cobros desde tu propio servidor, seguí el recorrido de integración que se describe más abajo.

## Direcciones del servicio

| Servicio | URL | Uso |
| --- | --- | --- |
| API | `https://padi.runasp.net` | Alta del comercio, creación de enlaces y consulta de cobros. |
| Aplicación Padi | [padi-billetera.netlify.app](https://padi-billetera.netlify.app/) | Interfaz de la billetera para sus usuarios. |
| Documentación | [padi-api.mintlify.site](https://padi-api.mintlify.site/) | Guías y referencia de integración. |

En los ejemplos, definí la URL base de la API sin agregar `/api/v1`:

```bash
export WALLET_API_URL="https://padi.runasp.net"
```

## Primera integración

1. [Registrá el comercio y obtené su API Key](/autenticacion).
2. [Creá un enlace de pago y abrí el checkout](/cobros).
3. [Consultá el cobro y conciliá el pedido](/confirmacion-de-pagos).

Conservá las credenciales y las llamadas autenticadas en tu servidor. El navegador del comprador recibe el enlace de checkout.

<Note>
La app publicada se identifica como un entorno de pruebas académico, sin dinero real. Los ejemplos usan datos ficticios y apuntan al backend alojado del proyecto.
</Note>
