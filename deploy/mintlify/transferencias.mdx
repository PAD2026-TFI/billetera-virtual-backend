---
title: "Transferir saldo"
description: "Consultar el destinatario y enviar una transferencia con una clave de idempotencia."
---

1. Consultá `GET /api/v1/me/transfers/recipient?destination=...` con el alias o CVU del destinatario. Mostrá el titular devuelto para que el cliente confirme el destino.
2. Generá un UUID nuevo y guardalo como `WALLET_TRANSFER_KEY` para esa transferencia.
3. Enviá el importe en ARS por la ruta que corresponde al identificador.

```bash
curl -i "$WALLET_API_URL/api/v1/me/transfers/by-alias" \
  -H "Authorization: Bearer $WALLET_JWT" \
  -H "Idempotency-Key: $WALLET_TRANSFER_KEY" \
  -H "Content-Type: application/json" \
  --data '{"alias":"destino.ejemplo","amount":1000}'
```

Para transferir por CVU, usá `POST /api/v1/me/transfers/by-cvu` con `cvu` y `amount`. La API devuelve `201` al crear la operación. Si se pierde la respuesta, reenviá el mismo cuerpo con la misma clave. Una repetición de una operación confirmada devuelve `200`, el mismo `id` y el encabezado `Idempotency-Replayed: true`. Consultá `GET /api/v1/me/wallet/movements` para actualizar el historial.
