## Crear y compartir el link

Desde tu servidor, usá la [API Key del comercio](/autenticacion) para crear un link de uso único. El importe está expresado en ARS.

```bash
curl "$WALLET_API_URL/api/v1/integrations/payment-links" \
  -H "X-Api-Key: $WALLET_MERCHANT_API_KEY" \
  -H "Content-Type: application/json" \
  --data '{"title":"Pedido de prueba","amount":1500,"type":"SingleUse"}'
```

La respuesta `201` incluye `id`, `token`, `checkoutUrl` y `qrCodeUrl`. Guardá el `id` del link junto al identificador del pedido en tu sistema. Redirigí al comprador a `checkoutUrl` o mostrá el QR de `qrCodeUrl` para que abra el checkout de Padi.

Si tu sitio necesita mostrar el importe o comprobar si el link sigue habilitado, usá `GET /api/v1/public/payment-links/{token}`. Para obtener el QR, usá `GET /api/v1/public/payment-links/{token}/qr`, que devuelve una imagen SVG.

## Conciliar el cobro

Consultá `GET /api/v1/integrations/payment-links/{id}` con tu API Key para conocer el estado del link. Si todavía no tenés el identificador del pago, consultá los cobros recientes y buscá el que tenga el `paymentLinkId` guardado con tu pedido.

```bash
curl "$WALLET_API_URL/api/v1/integrations/received-payments?limit=20" \
  -H "X-Api-Key: $WALLET_MERCHANT_API_KEY"
```

Con el `id` del pago, podés consultar `GET /api/v1/integrations/received-payments/{paymentId}`. Marcá tu pedido como pagado cuando la API confirme `status: "Succeeded"` y coincidan el link, el importe y la moneda. El regreso del comprador a tu sitio por sí solo no confirma el pago.
